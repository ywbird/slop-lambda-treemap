# Lambda Treemap

블로그 글: <https://meliplug.info/articles/math/lambda-treemap/>

람다 대수 식을 파싱해 2D binary treemap으로 시각화하고, 베타 축약이
일어나는 과정을 애니메이션으로 보여주는 웹 앱입니다.
외부 라이브러리 없이 HTML + Vanilla JS(ES modules) + CSS만으로 작성됐습니다.

## 기능

### 람다 대수 파싱
- 렉서 + 재귀 하강 파서: `λ` 또는 `\` 지원
- 커리 파라미터: `λx y. x` ≡ `λx. λy. x`
- 적용은 좌결합: `x y z` ≡ `(x y) z`
- 문법 오류는 위치와 함께 표시

### 베타 축약
- normal order (최외각/최좌측 redex 우선)
- 변수 캡처 회피 대입 + 알파 변환: `(λx. λy. x) y` → `λy1. y`
- 한 스텝 축약 / 자동 축약(연속 재생, 최대 200스텝 가드, 정규형 도달 시 종료)

### 트리맵 시각화
- **변수**: 바인딩마다 고유 색. 같은 바인딩은 축약 전후로 항상 같은 색
  (λ 노드에 비enumerable `bindingId`를 부여해 유지)
- **추상화**: "테두리를 가진 body"가 통째로 하나의 노드.
  부모 분할에서 원자적 셀이고, body는 깊이+1로 배치되어 가로/세로
  교차 분할에 한 단계로 반영됨
- **적용**: 대상 식(func)과 대입 식(arg)을 깊이 홀짝에 따라 좌우/상하
  교차 분할, 면적은 노드 수 비율로 분배
- **축약 애니메이션**: 축약 전/후 레이아웃을 셀 단위로 보간(morph).
  인자 복제본이 파라미터 변수 위치(들)로 이동하고, 나머지 식은 인자가
  차지하던 공간을 채우며 확장되며, 소비되는 λ 테두리는 페이드아웃
- 상단 상태 표시줄의 식도 트리맵과 같은 색 규칙으로 색칠됨

### `$` 변수
- `$2`처럼 숫자는 교회 숫자로 자동 치환: `$2 f x` → `f (f x)` (상한 $100)
- `$이름`은 접이식 변수 목록(`<details>`)에서 정의한 값으로 치환.
  값 안의 `$` 참조도 재귀 확장되며 순환 참조는 감지해 에러 처리

## 실행

ES modules를 사용하므로 정적 서버가 필요합니다 (`file://` 직접 열기 불가):

```sh
python3 -m http.server 8173
# 브라우저에서 http://localhost:8173 접속
```

## 사용법

- 입력 예: `(λx. λy. x) a b`, `\f x. f x`, `$id y`, `$2 f x`
- 버튼: 파싱 / 한 스텝 축약 / 자동 축약(실행 중 "정지"로 토글) / 초기화
- 입력칸에서 Enter로도 파싱됨
- 프리셋: K 조합자, 자기 적용, 다중 대입, 후속 숫자(교회 숫자 succ), 오메가(무한 축소 데모)

## 개발

```sh
npm test   # node --test — 103개 테스트
```

### 구조

```
index.html      UI 골격 (입력, 변수 목록, 프리셋, 버튼, canvas)
css/style.css   다크 테마 스타일
js/
  lexer.js      토큰화 (λ 또는 \, 점, 식별자, 괄호)
  parser.js     재귀 하강 파서 → AST
  ast.js        노드 팩토리(Var/Lambda/App + bindingId), pretty-printer
  reducer.js    자유 변수 계산, 캡처 회피 대입, 알파 변환, 한 단계/전체 축약
  treemap.js    트리맵 레이아웃(교차 분할, 가중치, 색) + 색 세그먼트
  renderer.js   canvas 렌더러 (devicePixelRatio, 리사이즈, morph 프레임)
  animator.js   축약 애니메이션 (전/후 레이아웃 morph, 복제 비행)
  variables.js  $변수 치환 (교회 숫자, 재귀 확장, 순환 감지)
  main.js       UI 배선 및 상태 관리
tests/          모듈별 테스트 (node:test)
```
